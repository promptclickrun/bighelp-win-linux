# Actual HTTP and injectable gateway adapters

2026-10-16. This slice implements the transport stage of [development execution](../DEVELOPMENT_EXECUTION.md). Source contracts are [transport policy](transport-policy.md), [protocol foundation](protocol-foundation.md), and [session contracts](session-contracts.md), including their pinned upstream receipts. No new wire method or route is inferred.

`boundedHttp` uses Node's built-in fetch with redirect refusal, omitted ambient credentials, a 20-second whole-operation deadline, AbortSignal propagation, and a response byte ceiling enforced while reading the decoded stream before assembling bytes. Fatal UTF-8 decoding and the existing RPC JSON scanner reject duplicate decoded keys, unsafe numbers, malformed Unicode and excessive nesting. A result envelope reuses that scanner without weakening the RPC envelope parser. Critical native response header duplicates (fetch combines them with commas) fail closed. Errors expose no transport URLs, headers, bodies or causes.

`connectGateway` captures the existing policy for origin, credentials, proxy headers and fresh single-use tickets. An injected socket factory supplies send/close; this module imports no socket dependency. Handlers are established before opening, ready can arrive before the factory resolves, and capability advertisement precedes the manifest probe. Bootstrap requires no session owner. Only finite session/profile operations, durably prepared text submission, and finite policy HTTP operations are exposed. Text returns its original RPC receipt envelope so the send domain distinguishes accepted streaming work from completion.

Lifetime AbortSignal and the caller's immutable current-generation predicate fence callbacks. Outbound requests and active inbound server requests each have a ceiling of 64; used outbound IDs and seen server IDs each have a ceiling of 4096. Duplicate server IDs cannot create another decision; changed-method duplicates retire the connection. Cancellation matches exact server ID and method, aborts the handler, and prevents a late response. Disconnect aborts all handlers. Mutations with lost acknowledgements fail as `outcome-unknown`; no operation is replayed. Application service owns host/principal/profile/session lease checks and safe unsupported-method responses through its required request handler.

Verification: six focused Node tests pass and all three strict TypeScript configurations pass. Actual local HTTP-server evidence covers redirect refusal, chunked response oversize, duplicate JSON keys, cancellation, and omitted ambient cookies across a Set-Cookie response. Synthetic gateway evidence covers both readiness timings, capability ordering, finite session encoding, exact cancellation, invalid frames, generation replacement, late callbacks, and lost mutation acknowledgements. No real Hermes host, TLS interception, packaged Electron runtime, Windows machine or Linux desktop was exercised by these tests. The HTTP byte ceiling bounds decoded application buffering; fetch/TLS internal allocations are platform-owned. The socket provider must independently enforce TLS, ticket deadline, cookie isolation, redirect refusal and frame bounds.
