# API source index

Pinned source evidence for the [Hermes contract](../contracts/HERMES_API.md) and [plugin contract](../contracts/PLUGIN_API.md). The full searchable data is [api-inventory.json](api-inventory.json). This index is source-derived, **not runtime-tested OpenAPI or a generated client**.

## Coverage and limitations

- workspace operations: **189**.
- central mapping blocks: **140**.
- http literal expressions: **280**.
- protocol name literals: **276**.
- swift type declarations: **979**.
- plugin route declarations: **116**.
- plugin model declarations: **112**.
- native feature literals (including imported capability constants): **36**.
- plugin tools: **34**.

Source: all `Bighelp/` Swift files except `Fixtures/` and `Demo*`; the two central dispatchers; all mounted plugin routers and their explicit workflow/wiki registries. Inventory retains file/line URLs, central case snippets, Python boundary model snippets, and scanned-file hashes. HTTP literals can be prefixes/interpolated expressions; protocol names can be events or config keys. Counts are **not counts of independently callable APIs**.

Exact DTO fields/constraints live in the linked source and imported contracts; inventory is not a finished TS type system. For secondary clients, follow the request enum, its finite route switch, bounded decoder, response model and tests. An unmapped operation is not authorization to send its application name as a gateway method.
